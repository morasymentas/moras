# Moras & Mentas

Sitio de la chacra de eventos Moras & Mentas (San José de Mayo, Uruguay).

- `index.html`: página de Servicio Premium para clientes.
- `panel.html`: panel del administrador (consultas, visitas, agenda de proveedores, usuarios).
- `agenda.html`: agenda de cada proveedor.
- `privacidad.html`: política de privacidad (la pide Meta para la app de WhatsApp).
- `mm-whatsapp.js`, `mm-whatsapp.css`: sección WhatsApp del panel (chats del bot).
- `bot/`: bot de WhatsApp con la API oficial de Meta y Claude. Cómo ponerlo en marcha: [bot/README.md](bot/README.md).
- `mm-datos.js`, `mm-sesion.js`, `mm.css`: conexión a la base de datos, inicio de sesión y estilos compartidos.
- `img/`: fotos del sitio.
